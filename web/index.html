Distributed Systems Concepts
Heartbeat Failure Detection
Workers send periodic heartbeats. Miss one timeout: SUSPECT. Miss two: DEAD. Tasks from dead workers auto-requeue.
HDFS NameNode, Cassandra Phi Accrual
Server-Streaming gRPC
Push-based task dispatch over long-lived streams. Zero polling overhead. First goroutine to read gets the task.
K8s watch API, gRPC load balancing
Priority Queue Scheduling
Tasks dispatched by priority (heap), then FIFO within same level. O(log n) via container/heap.
Linux CFS, K8s scheduler
Circuit Breaker
Per-worker breakers prevent sending tasks to failing workers. CLOSED / OPEN / HALF_OPEN states.
Netflix Hystrix, Envoy proxy
Exponential Backoff + Jitter
Retry delay = base * 2^attempt + random. Prevents thundering herd on failure storms.
AWS Architecture Blog
Dead Letter Queue
Tasks exhausting retries land here for inspection. Click Retry to requeue them.
Amazon SQS, RabbitMQ
At-Least-Once Delivery
Worker disconnects before ack? Master requeues. Tasks may run twice but never get lost.
MapReduce, SQS visibility timeout
Structured Concurrency
errgroup manages goroutine lifecycle. If any server fails, all cancel gracefully.
K8s controller-manager, CockroachDB
